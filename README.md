# FinTrack API

FinTrack API is a simple finance tracking application built to manage personal income and expense records. The main purpose of this project is to practise backend development concepts using Java and Spring Boot while building a practical and understandable REST API.

The application allows users to create, view, update, and delete financial transactions. Each transaction can represent either income or expense, helping users track their financial activity in a structured way.

## Purpose of the Project

This project is mainly created as a learning project to strengthen understanding of:

* Java backend development
* Spring Boot REST APIs
* CRUD operations
* Database integration
* Layered application structure
* Basic validation and exception handling
* API testing and development workflow

## Tech Stack

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL
* Maven
* REST API

## Current Features

* Add income and expense transactions
* View all transactions
* Find transactions by ID
* Update existing transactions
* Delete transactions
* Store transaction data in a database
* Basic API response handling

## Project Status

This project is still in progress and will continue to change as new features and improvements are added. The current version focuses on building a clean foundation for a simple finance tracking backend.

## Future Improvements

Planned improvements may include:

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project in your IDE.

3. Configure the database details in `application.properties`.

4. Run the Spring Boot application.

5. Test the API using Postman or any API testing tool.

## Note

This is a personal learning project created to improve backend development skills and understand how real-world REST APIs are structured.
